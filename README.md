### INSTALLATION

To install and play the TecKweez game on your local machine, follow these steps:

1. Clone the repository:

   ```groovy
   git clone https://github.com/tivereidoro/_.git
   ```

2. Navigate to the project directory:

   ```groovy
   cd project/
   ```

3. Run and play the app:
    ```groovy
   python project.py
   ```
